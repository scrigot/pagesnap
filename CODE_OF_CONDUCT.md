# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful, assume good faith, give constructive feedback, and do not harass anyone. Maintainers may remove comments, commits, or contributors that violate this.

**Reporting:** use GitHub's private vulnerability and abuse reporting on this repository, or contact the maintainer listed on the GitHub profile. Reports are handled confidentially.
