Privacy and permissions

  • activeTab Access the current tab only after you click PageSnap or press its shortcut.
  • scripting Inject the measuring and scrolling helper into that tab.
  • clipboardWrite Put the PNG on the clipboard.
  • storage Save these settings (synced by Chrome if sync is on).
  • downloads Optional, only if "Also download" is on.

Screenshots never leave this device. No analytics, no network requests, no accounts. The latest capture is kept in local extension storage so you can copy it again.
